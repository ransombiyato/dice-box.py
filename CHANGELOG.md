## [0.1.0] - 2026-10-20

### Changed

- Reset the repository to a fresh start. The previous single-file prototype
  (`Dice-box.py`) was removed.
- Replaced it with a standard Python project skeleton: `src/` layout,
  `pyproject.toml` packaging, a placeholder CLI, and a pytest suite.
- Added tooling: Ruff (lint + format), pytest, and a GitHub Actions CI workflow
  running lint, format checks, and tests on Python 3.9–3.13.
- Added `README.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, `LICENSE`, `.gitignore`,
  `.editorconfig`, and issue/PR templates.
